# 二、最重要的架构原则

MCP 是：

```
标准化 Tool / Resource 接入协议
```

MCP 不是：

```
业务逻辑层
```

MCP Server 不是：

```
新的 Flow Engine
新的 QA Engine
新的 Driver
```

正确：

```
MCP Server
    ↓
Platform HTTP API
    ↓
PlatformApi
    ↓
AEMP Core
```

禁止：

```
MCP Server
    ↓
subprocess
    ↓
docker
    ↓
EDA
```

也禁止：

```
MCP Server
    ↓
SQLite
```

或者：

```
MCP Server
    ↓
直接访问 runs/
```

实际：

```

    ↓

不要只返回：

```

```

 ↓

 ↓

 ↓

如果 MCP SDK 能直接提供 JSON Schema：

```

        ↓

# 二十三、MCP Tool Result

MCP 返回：

```
structuredContent
```

优先使用结构化结果。

不要把所有结果：

```
json.dumps(...)
```

变成一大段字符串。

Agent 最终需要：

```

```

与当前 M6.4/M6.5 模型兼容。

# 二十四、结果大小限制

当前 ToolResult 已有：

```
32 KiB
```

MCP 不能绕过这个限制。

因此：

```
MCP Result
 ↓
bounded serialization
 ↓
Agent ToolResult
```

超过限制：

```
截断
+
明确标记
```

不能无限把日志塞进模型 Context。

# 二十五、PolicyEngine

这是本阶段最重要的兼容点。

MCP 不允许绕过：

```
PolicyEngine
```

尤其：

```
run_flow
```

仍然：

```
HIGH RISK
```

因此最终执行路径必须是：

```
Agent
 ↓
MCP Tool Call
 ↓
PolicyEngine
 ↓
approval_required?
 ├── YES → interrupt
 │          ↓
 │       approve
 │          ↓
 │       MCP Tool
 │
 └── NO → MCP Tool
```

不要：

```
MCP Tool
 ↓
直接执行
```

# 二十六、HITL 设计

需要特别考虑：

> interrupt 应该发生在 MCP Tool 真正执行之前。

正确：

```
LLM
 ↓
MCP Tool Call
 ↓
Policy
 ↓
interrupt()
 ↓
Human Approve
 ↓
resume
 ↓
MCP call
 ↓
Tool execution
```

拒绝：

```
interrupt()
 ↓
reject
 ↓
APPROVAL_REJECTED
 ↓
LLM
```

不要：

```
MCP Server 已经执行
 ↓
才请求 approval
```

那样已经失去安全意义。

# 二十七、MCP Server 不负责 Approval

明确：

```
MCP Server
❌ PolicyEngine
❌ ApprovalManager
❌ HITL
```

这些属于：

```
Agent Runtime
```

MCP Server 是能力提供方。

权限决策属于 Agent orchestration/security layer。

# 三十五、Fallback

M7.2 默认：

> MCP 不可用时，不自动偷偷切换到 Local Tool。

原因：

如果：

```
MCP failed
 ↓
自动 local tool
```

可能导致：

- 行为不一致
- Policy 不一致
- 权限边界不一致
- 难以追踪

因此默认：

```
MCP unavailable
 ↓
structured failure
```

如果未来需要 fallback：

> 单独设计 Policy。

本阶段不做自动 fallback。

# 四十九、MCP 与 REST 的关系必须讲清楚

最终：

```
MCP
 ↓
“我要调用 run_flow”
```

Platform REST：

```
POST /api/v1/flows/run
```

两者不是竞争关系。

而是：

```
Agent-facing protocol
        ↓
       MCP
        ↓
Application-facing protocol
        ↓
       REST
```

MCP Server 是 Adapter。
