# 八、Graph State

新增明确的 Agent State。

不要直接使用 LangChain 的复杂 MessageState。

建议先建立自己的：

```python
@dataclass
class AgentState:
    messages: ...
    tool_round: int
    final_response: ...
    status: ...
```

具体字段可以根据当前项目调整。

至少需要表达：

```text
messages
tool_round
```

可以额外保存：

```text
final_response
status
trace
```

但不要过度设计。

---

# 九、State 的核心理解

State 是：

> Graph 在每个 Node 之间传递的数据。

例如：

```text
START
 ↓
State
{
    messages: [...]
    tool_round: 0
}
```

经过 Agent Node：

```text
State
{
    messages: [
        user,
        assistant(tool_call)
    ],
    tool_round: 1
}
```

经过 Tool Node：

```text
State
{
    messages: [
        user,
        assistant(tool_call),
        tool(result)
    ],
    tool_round: 1
}
```

再次进入 Agent Node：

```text
State
{
    messages: [
        user,
        assistant(tool_call),
        tool(result),
        assistant(final)
    ],
    tool_round: 1
}
```

# 十二、Conditional Edge

这是 M6.5 最重要的 LangGraph 概念之一。

实现：

```text
should_continue(state)
```

逻辑：

```text
if final answer:
    END

if tool_calls:
    tool_node

if tool_round >= MAX_TOOL_ROUNDS:
    END / failure
```

最终形成：

```text
Agent Node
    │
    ▼
should_continue
    │
    ├── "tools" → Tool Node
    │
    └── "end"   → END
```

不要把条件逻辑散落到多个地方。

# 二十二、Graph Compile

明确执行：

```python
graph = StateGraph(AgentState)

graph.add_node("agent", agent_node)
graph.add_node("tools", tool_node)

graph.add_edge(START, "agent")

graph.add_conditional_edges(
    "agent",
    should_continue,
    {
        "tools": "tools",
        "end": END,
    },
)

graph.add_edge("tools", "agent")

compiled_graph = graph.compile()
```

具体 API 根据安装的 LangGraph 版本调整。

不要使用：

```text
create_react_agent
```
