# 六、ToolDefinition

设计一个明确的 Tool Definition。

例如：

```python
@dataclass(frozen=True)
class ToolDefinition:
    name: str
    description: str
    input_schema: dict[str, Any]
```

要求：

- name 唯一
- description 明确
- input_schema 是 JSON Schema
- Tool Definition 可以直接转换成 OpenAI-compatible `tools` schema

例如：

```json
{
  "type": "function",
  "function": {
    "name": "list_runs",
    "description": "List historical EDA flow runs.",
    "parameters": {
      "type": "object",
      "properties": {
        "limit": {
          "type": "integer",
          "minimum": 1,
          "maximum": 100
        }
      },
      "additionalProperties": false
    }
  }
}
```

---

# 七、ToolCall

增加结构化 ToolCall：

```python
@dataclass(frozen=True)
class ToolCall:
    id: str
    name: str
    arguments: dict[str, Any]
```

例如：

```json
{
  "id": "call_123",
  "name": "list_runs",
  "arguments": {
    "limit": 10
  }
}
```

不要让 ToolCall 变成任意字符串执行接口。

---

# 八、ToolResult

增加结构化 Tool Result：

```python
@dataclass(frozen=True)
class ToolResult:
    tool_call_id: str
    tool_name: str
    status: Literal["success", "error"]
    data: Any | None
    error_code: str | None
    error_message: str | None
```

要求：

- 结构化
- 可序列化
- 有边界
- 错误不会直接 crash Agent
- 不暴露 API Key
- 不暴露内部 traceback
- 不暴露内部 filesystem 细节
- 不允许无限大的返回结果

---

# 九、Tool Protocol

设计统一 Tool Protocol。

例如：

```python
class AgentTool(Protocol):
    definition: ToolDefinition

    def execute(
        self,
        arguments: Mapping[str, Any],
    ) -> ToolResult:
        ...
```

Tool 本身只关心：

```text
输入参数
 ↓
业务调用
 ↓
ToolResult
```

# 二十、实现最小 Agent Loop

这是 M6.4 最核心的部分。

不要使用 LangGraph。

自己实现类似：

```python
for round_index in range(MAX_TOOL_ROUNDS):

    response = provider.chat(request)

    if not response.tool_calls:
        return final_answer

    append assistant tool-call message

    for tool_call in response.tool_calls:

        validate tool

        result = gateway.execute(tool_call)

        append tool result message

return failed
```

具体实现可以根据当前模型调整，但必须保持这个逻辑。

```text

```

或者通过配置控制。

例如：

```text
AEMP_AGENT_MAX_TOOL_ROUNDS=3
```

默认：

```text

```

```text

 ↓

LLM
 ↓
Tool
 ↓
LLM
 ↓
Tool
 ↓
无限循环
```

```text

```

并返回明确原因：

```text

```

不能无限调用。

# 二十三、Tool Error 处理

如果 Tool 执行失败：

例如：

```text

```

转换成：

```json

  "tool_call_id": "call_123",
  "tool_name": "list_runs",
  "status": "error",
  "error_code": "PLATFORM_CONNECTION_ERROR",
  "error_message": "Platform service is unavailable."

```

然后把这个结果返回给 LLM：

```text

        ↓

        ↓
LLM
```

允许 LLM 决定下一步。

但是：

```text

```

绝对不能因为 LLM 请求错误而绕过安全边界。
